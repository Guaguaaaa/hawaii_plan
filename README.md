# 🌺 Hawaii Oahu Trip Planner 2026 (夏威夷欧胡岛 6天5晚 旅行计划)

这是一个专为 **2026年8月16日 — 8月21日** 夏威夷欧胡岛 6天5晚之旅打造的响应式 Web App 旅行计划仪表盘，支持部署至 **GitHub Pages** 随身查阅。

## 🌟 项目亮点

* 📱 **双端优化**：
  * **桌面端**：多列宽屏大视图、每日完整行程比对、动态预算分析。
  * **移动端**：热带风卡片化 UI、一键 Google Maps 导航、关键预订码即点即复制、离线可用勾选清单。
* 🚗 **路线规划**：包含檀香山市区、东南海岸线自驾、北岸大环线、古兰尼牧场、珍珠港与钻石山。
* 💰 **预算与AA分账**：机票、酒店、租车、门票及餐食预算动态计算。
* ✅ **打包与备忘清单**：行前准备、必备证件、浮潜装备与特产购物清单。
