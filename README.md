# Oahu 2026 旅行工作台

为 2026 年 8 月 16 日至 8 月 21 日欧胡岛六天五晚行程制作的静态 PWA。桌面端用于规划、预约和准备，手机端用于查看当日安排、导航与旅行工具。

## 产品能力

- 日期自适应：出发前显示计划工作台，旅行期间显示今天和下一项，行程结束后进入回顾模式。
- 六日行程：桌面端采用六日概览与单日详情，手机端采用日期条和紧凑时间线。
- 准备中心：集中管理预约、待办与打包清单；勾选状态仅保存在当前设备。
- 旅行工具：住宿、租车、双时钟、天气、医疗和预算信息集中收纳。
- PWA：支持安装和离线打开；发现新版行程时提示用户刷新。
- 隐私：公开数据中不保存真实姓名、联系方式、家庭地址、证件号码或预订确认码。

## 维护方式

项目没有构建步骤或第三方运行时依赖。行程内容统一维护在 `js/data.js`，界面逻辑使用原生 ES modules：

```text
index.html          应用外壳与 PWA 元数据
css/style.css       响应式视觉系统
js/data.js          唯一可编辑行程数据源
js/state.js         日期模式、本机状态与迁移
js/views.js         四个页面及详情面板
js/app.js           路由、事件、天气和 PWA 更新
sw.js               离线缓存与版本更新
tests/              无依赖状态逻辑测试
```

本地预览时，从项目目录启动任意静态 HTTP 服务后访问根路径。运行 `node --test tests/state.test.mjs` 可验证日期模式、当前/下一项计算、路由与旧状态迁移。

## 部署

项目保留 GitHub Pages 与自定义域名部署方式。`robots.txt` 和页面元数据均禁止搜索引擎索引，但网站本身仍应只包含适合公开访问的信息。
